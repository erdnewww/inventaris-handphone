# Aplikasi Inventaris Barang

Aplikasi web sederhana untuk mengelola data inventaris barang.
Aplikasi ini dibuat untuk memenuhi tugas CRUD (Create, Read, Update, Delete)
data barang.

## Fitur

Aplikasi memiliki beberapa fitur utama:

- Tambah data barang (Create)
- Melihat daftar barang (Read)
- Edit data barang (Update)
- Hapus data barang (Delete)
- Pencarian data barang
- Validasi input
- Konfirmasi sebelum menghapus data

## Data Barang

Data barang yang disimpan terdiri dari:

- Kode Barang
- Nama Barang
- Jumlah
- Satuan
- Lokasi Penyimpanan

## Teknologi yang Digunakan

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Visual Studio Code
